# BSPHO Contact & Team Onboarding Card

If you have any issues with this repo (like making sure your entire team/table is in here) please send an email to **[secretary@bspho.be](mailto:secretary@bspho.be)**.

---

## Quick Email Template for Hackathon Team / Table Access

When emailing **[`secretary@bspho.be`](mailto:secretary@bspho.be)** to request repository access or organization invitations for your table, please include:

```text
Subject: [BSPHO GitHub Access] Table/Team <Number or Name> - <UC1 / UC2 / UC3 / UC4>

Hello BSPHO Secretariat,

Could you please grant our team access to our repository in the BelgianSPHO GitHub organization?

- Team / Table Name & Number: <e.g., Table 4 - Team PediSafe>
- Clinical Use Case Zone: <UC1 Red (OncoProtocol) | UC2 Green (PediDose) | UC3 Black (AImesis) | UC4 Blue (AutoICF)>
- Target Repository: <e.g., BelgianSPHO/uc2-team-pedisafe>
- GitHub Usernames (@handles):
  - @username1
  - @username2
  - @username3
  - @username4

Thank you!
```
